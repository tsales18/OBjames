Você pode incluir diversas instruções do compilador no código-fonte de um programa em C. Elas são chamadas de diretivas do Pré - processador e, embora não sejam realmente parte da linguagem de programação C, expandem o escopo do ambiente de programação em C

Como definido pelo padrão C ANSI, o Pré -processador de C contem as seguintes diretivas:
```
#if
#ifdef
#ifndef
#else
#elif
#endif
#incude
#define
#undef
#line
#error
#pragma
```

## # define
A diretiva `#define` define um identificador e uma string que o substituirá toda que vez que for encontrado no arquivo fonte. O padrão C ANSI refere-se ao identificador como um `nome de macro` e ao processo de substituição como `substituição de macro` forma geral: 
`#define nome_macro string`

Exemplo:
se definirmos a palavra VEDADEIRO para o valor 1 e a palavra FALSO para o valor 0, você declarará duas macros `#define`

```
#define VERDADEIRO 1
#define FALSO 0

printf("%d %d %d", FALSO, VERDADEIRO, VERDADEIRO + 1) <- 0, 1, 2
```

Se a string for maior que uma linha, você pode continuá-la na próxima colocando uma barra invertida no final da linha:

`#define STRING_LONGA "isso é uma string muito longa\que é usada como um exemplo"`

### Definindo macros semelhantes a funções

A diretiva `#define` possui outro recuso poderoso: o nome da macro pode ter argumentos. Cada vez que o nome do macro é encontrado, os argumentos usados na sua definição são substituídos pelos argumentos reais encontrados no programa:

```
#include <stdio.h>
#define ABS(a) (a)<0? - (a) : (a)

void main(void) {
printf("abs de -1 e 1: %d %d", ABS(1), ABS(1))
}
```

## # error
A diretiva ``#error`` força o compilador a parar a compilação. Ela é utilizada principalmente para depuração. forma geral:
```
#error mensagem_de_erro
```
A `mensagem_de_erro` não esta entre aspas. Quando encontrada, a mensagem de erro é mostrada.

## Diretivas de compilação condicional
Há diversas diretivas que permitem que você compile seletivamente porções de código-fonte do seu programa. Esse processo é chamado de compilação condicional e é utilizado amplamente em ``software houses `` comerciais que fornecem e mantêm muitas versões de um programa

### # if 
forma geral:
```
#if expressão_constante
	sequencia de comandos
#endif

se a expressão constante for vedadeira o codigo entre i if e endif é compilado

#define MAX 100

void main(void)
{
#if MAX>99
	printf("compilado para matriz maior que 99\n")
#else
    printf("compilado para uma matriz pequena\n")
#endif
}
```

### # ifdef e # ifndef
Um outro método de compilação condicional usa as diretivas `#ifdef` e `#ifndef` que significam "se definido" e "se não definido", forma gera:
```
#ifdef nome_da_macro
	sequencia de comandos
#endif
```

```
#ifndef nome_da_macro
	sequencia de comandos
#endif
```

### # undef
A diretiva `#undef` remove a definição anterior do nome de macro que a segue. 
```
#undef nome_da_macro
```
Ex:
```
#define LEN 100
#define WIDTH 100

char array[LEN][WIDTH];

#undef LEN
#undef WIDTH
```

### defined
Em adição a `#ifdef` existe uma segunda maneira de determinar se um nome de macro está definido. usando `#if` junto com `#defined` 

`defined nome_de_macro`
Ex:
```
#if defined MYFILE
    exp
#endif
```
ou, negando a expressão:
```
#if !defined DEBUG
	exp
#endif
```

### # line
A diretiva `#line` muda o conteúdo de _ _ LINE _ _
e _ _ FILE _ _  que são identificadores predefinidos do compilador. O identificador _ _ LINE _ _ contém o numero da linha atualmente sendo compilada. O identificador _ _ FILE _ _ é uma string que contém o nome do arquivo fonte sendo compilado. A forma geral:

```
#line número "nomearq"
```
onde número é qualquer inteiro positivo que se tornar o novo valor de  _ _ LINE _ _ e o ``nomearq ``opcional é qualquer identificador válido de arquivo que se torna o novo valor de _ _ FILE _ _ . `#line` é utilizada principalmente para depuração e aplicações especiais.

### # pragma
A diretiva `#pragma` é definida pela implementação e permite que várias instruções sejam dadas ao compilador. um compilador pode ter uma opção que suporte uma execução passo a passo (``tracing``) do programa. Uma opção de "trace" seria. então especificada por um comando `#pragma`. Você deve consultar o manual do usuário do seu compilador para obter detalhes e opções.

#### pack

Controla o **alinhamento e empacotamento** de estruturas (útil em protocolos industriais ou leitura de registradores de CLP).

Ex:
```
#pragma pack(push, 1)
struct Pacote {
    char c;
    int i;
};
#pragma pack(pop)
```

#### GCC diagnostic
Usado no GCC para controlar diagnósticos 

```
#pragma GCC diagnostic ignored "-Wunused-variable"
```

#### message
Imprime mensagens em tempo de compilação (muito útil para debug e análise condicional).

```
Imprime mensagens em tempo de compilação (muito útil para debug e análise condicional).
```

#### once
Evita múltiplas inclusões de um mesmo arquivo de cabeçalho.
```
#pragma once
// conteudp .h
```

## Os Operadores `#` e `##` do Pré - processador

O C ANSI fornece dois operadores do pré -processador: `#` e `##`. esses operadores são usados com uma declaração `#define`

o operador `#` transforma o argumento que ele precede em uma string entre aspas:

```
#include <stdio.h>
#define mkstr(s) # s

void main (void)
{
printf(mkstr(Eu gosto de C));
}
>>printf("Eu gosto de C")
```

O operador `##` concatena duas palavras.
```
#include <stdio.h>
#define concat(s)  a ## b

void main(void)
{
	int xy = 10;
	printf("%d", concat(x,y));
}
```

O pré - processador transforma
```
printf("d", concat(x,y))

em

printf("%d", xy);
```
