# O Operador ?
é deveras interessante e pode em alguns casos substituir o #if-then-else , onde EXP1 é avaliada e se for #true ,`RES` tem o valor de `EXP2` atribuída a si, e se falso tem o valor de `EXP3` atribuída a si.

`RES = EXP1 ? EXP2: EXP3;`

```
x=1
y = x>0 ? 1 : 0;

usando if-else:
x=1;
if (x>1) y=100;
else y = 200;

```

# Os Operados de Ponteiros & e *
Um ponteiro é um endereço na memória de uma variável. Uma variável de ponteiro é uma variável especialmente declarada para guarda um ponteiro para seu tipo especificado. 

# &
é um operador `unario`que devolve o endereço do seu operando, esse endereço é a posição interna da variável no computador, podemos imaginar `&` como significado "o endereço de" nesse caso: `*m recebe o endereço de count*`, `m` não tem nenhuma relação com o valor de `count`, sendo `count = 100`; e  sua posição de memoria 2000 para armazenar seu valor então `m = 2000;`

`count = 100;`
`m = &count;`
`m = 2000;`
# *
é um operador `unario que devolve o valor da variável localizada no endereço que o segue.
pense no `*` como, `*no endereço de*` sendo `q recebe o valor do endereço de m`

`q = *m;`
`q = 100;`

# O Operador em Tempo de Compilação sizeof
`sizeof` é usado para medir o tamanho em bytes de variáveis ou especificador de tipo, em parênteses, que o precede.

```
float f;
printf("%f", sizeof f);
printf("%d", sizeof (int));

8 bytes para float
2 bytes para int
```

# O Operador Vírgula
O lado esquerdo de um operador vírgula é sempre avaliado como `void`. Isso significa que a expressão do lado direito torna-se o valor de toda a expressão separada por vírgulas, `"faça isso e isso e isso`

`x = (y=3, y+1);`

# O Operadores Ponto (.) e seta (->)
Os operadores . (ponto) e -> (seta) referenciam elementos individuais de estruturas e uniões. 

# . (ponto)
O operador ponto é usado quando se está referenciando a estrutura ou união real.

# -> (seta)
O operador seta é usando quando um ponteiro para uma estrutura é usado
