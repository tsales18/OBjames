> ==Variáveis:==
é uma posição nomeada de memória, que é usada para guarda um valor, o nome da variável não tem relação com seu tipo ou valor
 `tipo nome_var;`
 `int i,j, 1;` %% declarando 2 variáveis como int = 1 %%
 `short int si;`

as variáveis são declaradas de três formas, dentro das funções, nos parâmetros de funções e fora das funções (variáveis locais, parâmetros formais e variáveis globais)

> ==Variáveis Locais==
Variáveis locais são declaradas apenas dentro de funções (blocos de código) e não existem fora dela

`void func1 (void) {int x; x = 10;}`

==Variáveis Globais==
As variáveis globais diferente das locais são declaradas fora das funções, pode ser usada em toda parte do código, e mantem o valor declarado por todo código.
