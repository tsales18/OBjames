Uma matriz é uma coleção de variáveis do mesmo tipo que é referenciada por um nome comum, um elemento especifico em uma matriz é acessado por meio de um índice. Em C todas as matrizes corresponde ao primeiro elemento e o mais alto, ao ultimo elemento. Matrizes podem ter de uma a várias dimensões. a matriz mais comum em C é a de string, que é simplesmente uma matriz de caracteres terminada por um nulo. Essa abordagem a Strings dá a C maior poder e eficiência que ás outras linguagens.
Em C, matrizes e ponteiros estão intimamente relacionados; uma discussão sobre um deles normalmente refere-se ao outro. 

uma matriz sem índice aponta para seu primeiro elemento:

```
char str[80] = {a,b,c,d};
char x;

x = str

printf("%s",x) <- a
```
