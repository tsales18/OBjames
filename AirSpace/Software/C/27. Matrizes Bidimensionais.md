Matrizes bidimensionais em C são **arrays de arrays**, ou seja, uma tabela com **linhas e colunas**,como em uma planilha.

forma geral:
```
tipo nome[linhas][colunas
```

```
int matriz[3][4];  // 3 linhas, 4 colunas

```

```
int matriz[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

int matriz[2][3] = { {1,2,3}, {4,5,6} };

// Internamente: 1 2 3 4 5 6


```

matriz de strings
```
#include <stdio.h>

int main() {
    char nomes[3][10] = {
        "Ana",
        "João",
        "Luiz"
    };

    for (int i = 0; i < 3; i++) {
        printf("Nome %d: %s\n", i + 1, nomes[i]);
    }

    return 0;
}

```

Matriz não dimensionada bidimensional:
```
int matriz[][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

```
