Um ponteiro é uma variável que contém um endereço de memória. Esse endereço é normalmente a posição de uma outra variável na memória. se uma variável contém o endereço de um outra, então a primeira variável é dita para a apontar para a segunda 
Ponteiros tem três funções principais em C.

1. Eles podem fornecer uma maneira rápida de referenciar elementos de uma matriz.

2. Os ponteiros também permitem que as funções em C modifiquem seus parâmetros de chamada.

3. Eles suportam listas encadeadas e outras estruturas dinâmicas de dados.

4. Forma geral de um ponteiro: `tipo *nome;

5. Um ponteiro suporta apenas ENDEREÇOS e não valores
# Operadores de ponteiros

``&``: 
```
Devolve o endereço de memoria do seu operando

m = &count;

coloca em 'm' o endereço da memoria que contem a variavel count.

"O endereço de"

"m recebe o endereço de count"

Exemplo 2:
void main(void){
int x = 10;
int *p1, *p2;

p1 = &x;
p2 = p1; //agora p1 e p2 apontas para x.
}
```

`*:`
```
Devolve o valor da variavel locazida no endereço de memoria

q = *m;

coloca em 'q' o valor da variavel locazido no endereço 'm'

"no endereço de"

"q recebe o valor que está no endereço m"
```

# Atribuição de Ponteiros

é possível atribuir o endereço de um ponteiro para outro.
```
void main(void)
{
int x;
int *p1, *p2;

p1 = &x;
p2 = p1;

printf("%p", p2) <escreve o endereço de x não seu valor
}


Exemplo 2:
int x = 10;
int *p = &x;

x = numero decimal, 10
&x = endereço de memoria, 0x7ffdea2bac

```
