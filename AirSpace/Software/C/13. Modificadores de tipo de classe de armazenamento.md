`definem **visibilidade/scope**`
Especifica para o compilador como a variável deve ser armazenada.

- `extern
   é um especificador que permite que variáveis de um arquivo seja visível em outro.
   arquivo1:
   `int x, y;
   `char ch;`
   `main(void)
   `{}`
   `func1()`
   `{
   x = 123;
   `}
   
   arquivo2:
   `extern int x, y;`
   `extern char ch;`
   `func22(void)`
   `{`
   `x = y/10;`
   `}`
   `func23()`
   `{`
   `y = 10;`
   `}`
   
- `static`
  em variáveis locais tem como objetivo manter o valor da variável entre chamadas da função. 
  em variáveis globais tem como objetivo impedir que ela seja vista em outro arquivo, assim, inutilizando a keyword `extern`, tem o mesmo objetivo quando usada no inicio de funções.
  `int james(void)
  `{
   `static sales;
   `sales = 100;
   `sales = sales + 18;`
   `return (sales);` 
  `}`

- `register
   tem como objetivo aumentar a velocidade de acesso a uma variável, sendo ela apenas, variáveis locais e parâmetros formais, e sugere que a variável seja armazenada em registrador na CPU em vez da RAM, Toda var pode ser definida como `register`, mas nem todas recebem a mesma otimização, maior eficiência em var do tipo `int` e `char`

   `int_pwr(register int m, register int e)`
   `{`
     `register int temp;`
     `temp = 1;`
     `for(; e; e--) temp = temp *m;`
     `return temp;`
  `}`
