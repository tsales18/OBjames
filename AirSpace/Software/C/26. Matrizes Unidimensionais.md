forma geral para declarar uma matriz unidimensional:
`tipo nome_var[tamanho]`

```
double balance[100];
```

Em C, toda matriz tem com 0 o índice do seu primeiro elemento.
```
char a[7];
elemento a[0] a[1] a[2] a[3] a[4] a[5] a[6]
endereço 1000 1001 1002 1003 1004 1005 1006

int numeros[5] = {10, 20, 30, 40, 50};

numeros[0] = 99;       // altera o primeiro elemento
int x = numeros[2];    // lê o terceiro elemento

for(int i = 0; i < 5; i++) {
    printf("Elemento %d: %d\n", i, numeros[i]);
}

```

int sample[10];
