Em um processador de texto ou um banco de dados aproveita toda RAM de um sistema. Porém, como a quantidade de RAM varia entre computadores esses programas não poderão usar variáveis normais. Em vez disso, esses e outros programas alocam memória, conforme necessário, usando as funções do sistema de alocação dinâmica de C.

## malloc()
aloca memória.
```
void *malloc(size_t numero_de_bytes);

numero_de_bytes = é o numero de bytes de memória que você que alocar


```
## free()
libera memória.
