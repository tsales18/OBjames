# fopen()
```
C FILE *FOPEN(const char *filename, const char *mode)
```
Esta função aceita os seguintes parâmetros -

- **Filename:** Uma string que representa o nome do arquivo a ser aberto. Isso pode incluir um caminho absoluto ou relativo.
- **modo:** Uma cadeia de caracteres que representa o modo em que o arquivo deve ser Aberto. Os modos comuns incluem:

- "r": Aberto para leitura. O arquivo deve existir.
- "w": Aberto para escrita. Cria um arquivo vazio ou trunca um arquivo existente arquivo.
- "a": Aberto para anexação. Grava dados no final do arquivo. Cria o se ele não existir.
- r+": Aberto para leitura e escrita. O arquivo deve existir.
- "w+": Aberto para leitura e escrita. Cria um arquivo vazio ou trunca um arquivo arquivo existente.
- a+": Aberto para leitura e anexação. O arquivo é criado se não existir.
