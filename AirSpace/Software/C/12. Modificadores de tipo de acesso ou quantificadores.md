`alteram a **qualificação de acesso** à memória`
Controlam a maneira como as variáveis podem ser acessadas ou modificadas:

- const.:
   variáveis declaradas como const. não podem ser modificadas pelo programa
```
const usado em variaveis do tipo char:
- const char sozinho: um char.
  
- const char[] com "texto": um array que guarda uma string. 
  
- const char* [] com `{"A","B",...}`: várias strings** (cada item é um ponteiro 
  para uma string).
  
- const char [N][M]`”: matriz com N strings, cada uma com capacidade Mchars.
   
```

- volatile.:
   é usado em variáveis em que eventos externos alteram o valor de uma variável sem comando do programa
