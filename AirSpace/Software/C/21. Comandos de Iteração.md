permite que um conjunto de instruções seja executado até que ocorra uma certa condição,
essa condição pode ser predefinida(como no laço `for`) ou com final em aberto (como nos laços while e do-while).

### for
A forma geral do comando `for` é:
```
for(inicialização; condição; incremento) comando;
```

onde a `condição` deve de verdadeira para executar o laço e o `comando`:
```
int x;
for(x=1; x<=10; x++)printf("%d",x);
```

Com operador virgula:
```
int x;
for (x=0, y=0; x+y<10; ++x)
{
y=getchar();
y=y-'0'
}
```

Usando for para login:
```
void sign_on(void)
{
char str[20];
int x;
for(x=0; x<3 && strcmp(str, "senha"); ++x)
{
printf("Digite a senha por favor:");
gets(str);
}
if (x==3) return;
else /* conecta o usuario...*/
}
```

O Laço infinito:
```
for(;;) printf("executar e executar");
```
Laços for sem corpo
```
utilizado para atraso de tempo

for( ; *str ==''; str++);
```


# while 
forma geral:
```
se a condição for verdadeira, o comando é executado

while(condição) comando;
```

wait_for_char9(void)
```
{
char ch;
ch = '\0';
while(ch!='A') ch=getchar();
return ch;
}
```

# do-while
forma geral:
```
do{comando} while(condição);
```

