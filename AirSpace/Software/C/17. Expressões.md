Operadores, constantes e variáveis são elementos que constituem uma expressão

###### Casts
Usada para forçar uma expressão ser de um tipo
`(tipo) expressão`
onde (tipo)é qualquer tipo de dado valido em C.
`(float) x/2`

###### Espaçamento e Parênteses
é possível adicionar tabulações e espaços a expressões para torna-las mais legíveis.

```
x=10/y - (12/x);

x = 10 / y - (12/x);
```
