C tem quatro comandos que realizam um desvio incondicional: `return` , `goto`, `break` e `continue`. Destes, você pode usar `return` e `goto`  em qualquer lugar em seu programa. Você pode usar os comandos `break` e `continue` em conjunto com qualquer  dos comandos de laço. Como discutido anteriormente neste capitulo, você também pode usar o `break` com `switch`.

# return
forma geral:
```
return expressão;
```

uma função declarada como void não pode ter um comando `returm` especifique um valor. (como uma função void não retorna valor, não tem sentido que o comando `return` especifique um valor nas funções `void`)
