###### Constantes Caractere de Barra Invertida

| Código | Significado                                   |
| ------ | --------------------------------------------- |
| \b     | Retrocesso (BS)                               |
| \f     | Alimentação de formulário (FF)                |
| \n     | Nova linha (LF)                               |
| \r     | Retorno de carro (CR)                         |
| \t     | Tabulação horizontal (HT)                     |
| \ "    | Aspas duplas                                  |
| \ '    | Aspas simples                                 |
| \0     | Nulo                                          |
| \ \    | Barra invertida                               |
| \v     | Tabulação vertical                            |
| \a     | Alerta (beep)                                 |
| \N     | Constate octal (onde N é uma constante octal) |
| \xN    | Constate hexa (onde N é uma constante hexa)   |
