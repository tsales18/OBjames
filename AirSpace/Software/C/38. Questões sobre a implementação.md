

## Parâmetros e Funções de Propósito Geral:
```
Não deve basear funções de proposito geral em dados globais. Todas as informações de que uma função precisa devem ser passadas para ela por meio de sues parâmetros.
```

## Eficiência:
```
Código em linha é mais rapido que a chamada a uma função por por duas razões.

1- Uma instrução CALL leva tempo para ser executada.
2- Se há argumentos para passar eles devem ser colocados na pilha, o que também toma tempo.

para maioria das aplicaçoes,esse aumento muito pequeno no tempo de execução não é significativo.Mas se for, lembre-se que cada chamada à função usa um tempo que poderia ser economizado se o código da função fosse colocado em linha.


em linha:

#include <stdio.h>
void main (void)
{
int x;
for x=1; x<11; ++x)
printf("%d", x*x);
}

chamada à função:
#include <stdio.h>
int sqr(int a);
void main(void)
{
int x;
for x=1; x<11; ++x)
printf("%d", sqr(x))
}

sqr(int a)
{
return a*a
}
```
