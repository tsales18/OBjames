Em C, ponteiros e matrizes estão intimamente relacionados. Como você sabe, um nome de matriz sem um índice é um ponteiro para o primeiro elemento da matriz. 

```
char p[10];

são iguais:
p
&p[0]

de outra forma:
if (p == &p[0]) >>verdadeiro

Exemplo 2:
int *p, i[10];
p = i;
p[5] = 10; //atribuimos o valor '10' no indice 5 de i
```


```
#include <stdio.h>

int main() {
    int valores[] = {10, 20, 30};
    int *ptr = valores;

    printf("%d\n", ptr[0]); // 10
    printf("%d\n", ptr[1]); // 20
    printf("%d\n", ptr[2]); // 30

    return 0;
}

```
