#### Camada de aplicação
>Essa camada controla e executa os comandos reais especificados ente os nós. Essa camada é a mesma para DF1 e links de rede.
- interface para processos de usuário e bancos de dados
- interpreta comandos
- formata os dados do usuário em pacotes
- a camada de aplicação depende do tipo de nó que o aplicativo está sendo executado, pois deve fazer interface com o processo do usuário e interpretar o banco de dados do usuário
##### Processos na camada de aplicação
> A camada de aplicação é normalmente organizada em dois tipos de processos:

- remetentes: Um remetente, depois de receber um sinal do userprocess envia uma mensagem e aguarda uma resposta. Em seguida, ele envia os resultados para o processo do usuário.

- respondentes: Um respondente aguarda uma mensagem recebida do link. Quando o respondente recebe uma mensagem, ele executa a operação indicada no banco de dados do usuário e retorna uma mensagem de resposta ao remetente. 


| Se o seu link físico for                                            | então                                                          |
| ------------------------------------------------------------------- | -------------------------------------------------------------- |
| um link de rede                                                     | Os módulos de comunicação cuidam automaticamente dessa camada. |
| um link DF1 entre os módulos de interface AllenBradley              | Os módulos de interface cuidam automaticamente dessa camada    |
| um link DF1 entre um módulo Allen Bradley interface e um computador | Você precisará programar essa camada em seu computador         |
