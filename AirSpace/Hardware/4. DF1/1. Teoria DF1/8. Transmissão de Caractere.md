Os módulos de interface Allen-Bradley enviam dados em série pela interface RS232-C/RS-422-A, um Byte de 10 bits - byte de 11 bits com paridade - por vez. O formato de transmissão está em conformidade com os padrões(ANSI X3.16, CCITT V.4, and ISO 1177 standards) , com a exceção de que o bit de paridade é mantido enquanto o comprimento dos dados é estendido para oito bits. Formato de transmissão é:

```
No Parity
start bit
data bit 0
data bit 1
data bit 2
data bit 3
data bit 4
data bit 5
data bit 6
data bit 7
one stop bit
```

```
With Parity
start bit
data bit 0
data bit 1
data bit 2
data bit 3
data bit 4
data bit 5
data bit 6
data bit 7
even parity bit
one stop bit
```
