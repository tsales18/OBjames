O algoritmo de sondagem mestre varia dependendo do fluxo de tráfego esperado
através do sistema. Um mestre simples sonda continuamente cada escravo em
modo "round-robin". Se uma mensagem for recebida, ela é processada e, em
seguida, o próximo nó é sondado. Além das responsabilidades gerais, os
mestres são responsáveis ​​por:
• Detecção de duplicatas
• Sondagem de escravos inativos
• Alívio de filas de mensagens cheias
• Uso de uma camada de rede simplificada
• Retransmissão de mensagens entre escravos

>Se um escravo não responde a uma pesquisa, o mestre o remove da lista de escravos ativos. Para economizar tempo, o mestre pesquisa os escravos ativos regularmente e pesquisa os escravos inativos ocasionalmente para ver se eles respondem. Quando um escravo inativo não responde a uma pesquisa, ele é colocado de volta na lista de escravos ativos.

>As informações de detecção de duplicatas devem ser mantidas para cada nó, a menos que
 o nó mestre consulte cada nó repetidamente até que esteja vazio, antes de
 prosseguir para o próximo. Nesse caso, as informações de detecção de duplicatas só
 precisam ser mantidas para o nó atual.

>Quando um nó atinge o tempo limite para um comando de mensagem, consulte o nó para ver se ele responde. Se ele responder à consulta com um DLE EOT, mas falhar consistentemente em confirmar o recebimento da mensagem (ACK), seu buffer provavelmente está cheio. Você deve esperar que os buffers sejam liberados antes de enviar outra mensagem.

>Alguns dispositivos retêm dados indefinidamente. Para obter os dados e resolver a
 condição de buffer cheio, você deve consultar o dispositivo.
 Quando a origem e o destino das mensagens de um nó compartilham um pool de memória
 comum, um excesso de mensagens na origem pode causar uma indicação de
 destino de mensagens cheio. Nesse caso, o mestre pode consultar o
 nó para receber mensagens e liberar memória. Esperar que a memória
 seja liberada automaticamente pode não funcionar em todos os dispositivos; a única
 maneira de liberar memória é o mestre consultar o nó.
