DLE STX | DST | SRC | CMD | STS | TNSL | TNSH | FNC | DADOS... | DLE ETX | BCC


| Ordem     | Campo                  | Tamanho (bytes) | Significado técnico                                                                                        | Explicação detalhada                                                                                                                                                                             |
| :-------- | :--------------------- | :-------------- | :--------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1-2**   | `DLE STX`              | 2               | Inicio da mensagem                                                                                         |                                                                                                                                                                                                  |
| **3**     | `DST`                  | 1               | Destination Node                                                                                           | Número da estação **destino** — o endereço do equipamento que deve responder. Exemplo: se for 0x00, é o CLP mestre; se for 0x02, é um escravo.                                                   |
| **4**     | `SRC`                  | 1               | Source Node                                                                                                | Número da estação **origem** — quem está enviando a mensagem.                                                                                                                                    |
| **5**     | `CMD`                  | 1               | Command                                                                                                    | Código da função/protocolo. Define o que será feito (por exemplo: leitura, escrita, diagnóstico, etc.). Exemplos: `0x0F` = Protected Typed Logical Write, `0x0E` = Protected Typed Logical Read. |
| **6**     | `STS`                  | 1               | Status                                                                                                     | Usado **somente nas respostas**. O CLP retorna aqui um código de erro ou 0x00 se tudo ocorreu bem. (Durante o envio, esse byte geralmente é 0x00 ou omitido.)                                    |
| **7**     | `TNSL`                 | 1               | Transaction Sequence Number (Low byte)                                                                     | Número de sequência da transação (parte baixa). Serve para **sincronizar requisições e respostas**: o mestre envia um número, e o escravo o repete na resposta.                                  |
| **8**     | `TNSH`                 | 1               | Transaction Sequence Number (High byte)                                                                    | Parte alta do número de sequência TNS. Os dois bytes juntos formam um identificador de 16 bits para a transação.                                                                                 |
| **9**     | `FNC`                  | 1               | Function/Subcommand                                                                                        | Código da subfunção associada ao comando principal. Por exemplo, em um comando de leitura, indica **o tipo de arquivo** (dados, status, bits, etc.).                                             |
| 10        | **Byte size**          | 1               | Quantos bytes cada elemento tem (ex: 2 bytes para inteiros, 4 para floats).                                |                                                                                                                                                                                                  |
| 11        | **File number**        | 1               | Número do arquivo no CLP (ex: arquivo 7 → N7, arquivo 8 → F8).                                             |                                                                                                                                                                                                  |
| 12        | **File type**          | 1               | Tipo do arquivo: • `0x89` = Integer (N) • `0x8A` = Floating Point (F) • `0x85` = Bit (B).                  |                                                                                                                                                                                                  |
| 13-14     | **Element number**     | 2               | Endereço do elemento dentro do arquivo (ex: `N7:10` → elemento 10 → `0x0A 0x00`). Ordem _low-byte first_.  |                                                                                                                                                                                                  |
| **15-16** | **Sub-element number** | 2               | Usado em arquivos com estrutura composta (geralmente 0x00 0x00 para elementos simples).                    |                                                                                                                                                                                                  |
| **17**    | **Data (opcional)**    | Variável        | Presente apenas em comandos **de escrita**. Contém os valores reais a serem gravados (em _little endian_). |                                                                                                                                                                                                  |
| **18-19** | `DLE ETX` (0x10 0x03)  | 2               | _End of Text_                                                                                              | Indica o fim dos dados. Assim como o `DLE SOH` indica o começo do cabeçalho, o `DLE ETX` marca o fim da parte útil.                                                                              |
| **20**    | `BCC`                  | 1               | Block Check Character                                                                                      | Byte de verificação (checksum). Calculado fazendo o **soma (com complemento de dois)** de todos os bytes entre o `DLE SOH` e o `DLE ETX`. Se a soma for incorreta, o receptor rejeita o frame.   |
