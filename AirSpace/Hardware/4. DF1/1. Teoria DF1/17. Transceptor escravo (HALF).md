Como a entrada enviada para o transceptor pode ser frequentemente afetada por ruído
do mundo físico, o transceptor deve ser capaz de
responder a muitas situações adversas, tais como:
• O buffer de mensagens pode estar cheio, não havendo espaço para armazenar uma mensagem
• Uma mensagem pode conter um erro de paridade
• O BCC/CRC pode ser inválido
• O DLE SOH, DLE STX ou DLE ETX BCC/CRC podem estar
ausentes
• A mensagem pode ser muito longa ou muito curta
• Um símbolo de controle ou de dados espúrio pode ocorrer fora de uma mensagem
• Um símbolo de controle espúrio pode ocorrer dentro de uma mensagem
• A resposta DLE ACK pode ser perdida, fazendo com que o transmissor
envie uma cópia duplicada de uma mensagem que já foi transmitida
para o buffer de mensagens

>O escravo está sempre em modo passivo até receber uma mensagem.
  Enquanto aguarda uma mensagem, qualquer mensagem diferente de DLE SOH ou DLE ENQ é ignorada. (Em um sistema de circuito único, os escravos devem
  ser capazes de ignorar com segurança tudo o que é enviado por outros escravos.)

>Quando o byte de sincronização `DLE SOH` é recebido, o BCC/CRC e o buffer de mensagens são redefinidos. O próximo símbolo recebido deve ser um símbolo de dados e deve ser igual ao endereço do nó (ou 255 se o nó puder receber mensagens de broadcast).

>O próximo símbolo é recebido e deve corresponder a `DLE STX`. Se o
   endereço do símbolo não corresponder, o nó ignora o restante da
   mensagem e começa a construir uma nova mensagem a partir desse símbolo.

| simbolo e o nó | então                                                                                |
| -------------- | ------------------------------------------------------------------------------------ |
| não é igual    | O nó ignora o restante da mensagem<br>e continua aguardando o início da<br>mensagem. |
| é igual        | adiciona no BCC/CRC                                                                  |

>Durante a construção da mensagem, todos os símbolos de dados são armazenados no buffer da mensagem e adicionados ao BCC/CRC acumulado. O dispositivo escravo define um sinalizador de erro para indicar a ocorrência de um erro de paridade, estouro de buffer, enquadramento de mensagem ou erro de comunicação com o modem.

>Se qualquer símbolo de controle diferente de DLE ETX BCC/CRC for recebido
no final do pacote, a mensagem será descartada e toda a entrada será
ignorada até que o próximo DLE SOH ou DLE ENQ seja recebido. Quando o
DLE ETX BCC/CRC for recebido, o sinalizador de erro, o BCC/CRC, o
tamanho da mensagem e o endereço (opcionalmente) serão todos verificados.

| se DLE ETX e BCC/CRC | então                                             |
| -------------------- | ------------------------------------------------- |
| incorreto            | a mensagem é ingnorada                            |
| correto              | o escravo começa a detecção de mensagem duplicada |
>O dispositivo escravo compara os bytes SRC, CMD e ambos os bytes TNS com os bytes correspondentes da mensagem anterior.

Se os bytes são iguais:
Descarta a mensagem e envia ACK

Diferentes 
verifica o estado do receptor da mensagem:
- Quando a fila de mensagens está cheia, o transceptor descarta a mensagem atual e não responde.

- Quando mensagem indica que o receptor não está cheio, o transceptor:
	- Transfere os dados do nível de link atual para o receptor de mensagens
	- utiliza os primeiros quatro bytes dos dados do nível de enlace atual para detecção de mensagens duplicadas.
	- Envia ACK
	
>Se Enquanto aguarda uma mensagem, uma pesquisa (DLE ENQ STN BCC) é recebida; o transceptor aceita os dois caracteres seguintes. O último caractere é um BCC e não é preenchido com bytes de escape. Se o endereço da estação não corresponder ou houver um erro, a pesquisa é ignorada. Se a pesquisa for aceita, existem três situações possíveis.

>O transceptor ainda pode estar retendo uma mensagem que transmitiu anteriormente, mas que não foi confirmada. Há um limite para o número de vezes que cada mensagem de resposta pode ser enviada.

| se o limite é: | então:                                                                                                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| excedido       | Quando a pesquisa é recebida, a mensagem de resposta é retornada à<br>fonte da mensagem com uma indicação de erro, e o transceptor tenta<br>enviar a próxima mensagem da fonte da mensagem. |
| não excedido   | A resposta à pesquisa é reenviar a mensagem de resposta atual.                                                                                                                              |
>A mensagem está atualmente retida; o transceptor tenta obtê-la da fonte da mensagem.

| se:                         | então:                                                                                       |
| --------------------------- | -------------------------------------------------------------------------------------------- |
| A mensagem está disponível. | O transceptor inicializa seu contador de tentativas e o transmite em resposta à solicitação. |
| Não disponível.             | A resposta a uma pesquisa é transmitir um DLE EOT.                                           |
###### Transmitir um mensagem:
>Quando uma mensagem é transmitida após o recebimento de uma solicitação de sondagem, seu formato é
idêntico ao de um pacote de mensagem full-duplex. Após o envio da mensagem,
o transceptor retém a mensagem até que um DLE ACK seja recebido, ou
até que o número de vezes que a mensagem foi solicitada exceda o limite.

###### Receber DLE ACK
>Quando um ACK (confirmação de recebimento) é recebido, a mensagem atualmente armazenada é
descartada e a origem da mensagem é notificada de uma entrega bem-sucedida.
Quando a próxima pesquisa for recebida, a próxima mensagem disponível da
fonte de mensagens será enviada (ou um DLE/EOT).
