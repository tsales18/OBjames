A camada física consiste em cabos e módulos de interface que permitem a comunicação entre os nós (dispositivos com endereço na rede)

ao conectar um computador serialmente a um link DH, DH+, ou ControlNet, o módulo de interface atua como ponte entre:

>o link DF1 (RS-232 ou RS-422-A)
>o link de rede (DH, DH+, DH485 ou ControlNet)

o link DF1 fornece:
>comunicação `mestre-escravo`via protocolo `half-duplex`

>Comunicação ponto-a-ponto (peer-to-peer)via protocolo `full-duplex`

#### Tipos de link de rede

| Link           | Conecta                                           | Capacidade                   |
| -------------- | ------------------------------------------------- | ---------------------------- |
| **DH**         | PLC-2, PLC-3, PCs, hosts, dispositivos RS-232/422 | até 64 nós (255 com bridges) |
| **DH+**        | Mesmo que DH + PLC-5 e SLC 5/04                   | até 64 nós                   |
| **DH485**      | SLC 500, PCs, IHMs                                | até 32 nós                   |
| **ControlNet** | PLC-5, IHMs, PCs, I/O                             | até 99 nós                   |

### Link DH
>Um link DH consiste em um cabo tronco de até 10.000 pés (3.048 metros) de comprimento e cabos drop de até 100 pés (30,48 metros) cada. Cada nó está na extremidade de um cabo drop e se conecta ao link DH por meio de um conector de estação (cat. nº 1770-SC). Esta é a única configuração testada e suportada pela Allen-Bradley.
>Um link DH implementa a comunicação ponto a ponto por meio de um esquema chamado mestre flutuante. Com esse arranjo, cada nó tem acesso igual para se tornar o mestre. Os nós licitam o domínio temporário com base na necessidade de enviar informações.
>Ao contrário de uma relação mestre/escravo, uma relação mestre flutuante não exige que o mestre atual pesquise cada nó para conceder permissão para transmitir. Portanto, ele fornece uma rede mais eficiente porque há menos sobrecarga - ou seja, tempo - por transação.

- Rede local (LAN) para ambientes industriais
    
- Até 64 dispositivos, 57.6 kbps
    
- Topologia com cabo tronco (máx. 3048 m) e ramais (máx. 30 m)
    
- Comunicação **ponto-a-ponto** com esquema de **mestre flutuante** (qualquer nó pode assumir a função de mestre temporariamente)

### Link DH+
>Um link DH+ é semelhante a um link DH, mas é usado de forma ideal para redes menores que consistem em nós limitados (cerca de 15 no máximo). Um DH+link aceita 64 dispositivos e pode transmitir dados em 57.6, 115.2 ou
230,4 mil bits. (Os processadores PLC-5/250, SLC e PLC suportam 57,6 e 115,2 K bits; Os processadores SLC 5/04 suportam 230,4K bits; Espera-se que os processadores PLC-5 suportem 230,4 K bits no início de 1997.)
>Um link DH+ implementa a comunicação ponto a ponto com um esquema de passagem de token para girar o domínio do link entre os nós conectados a esse link.

- Similar ao DH, mas com foco em redes menores (~15 nós)
    
- Suporte a 57.6, 115.2 e 230.4 kbps
    
- Comunicação **ponto-a-ponto** com **passagem de token**

### Link DH485
>Link DH485Um link DH485 é um link de programação ponto a ponto e aquisição de dados de baixo custo para uma variedade de produtos Allen-Bradley. A topologia DH485 é semelhante à topologia DH e DH+. Você pode conectar até 32 nós a um link DH485.
O link DH485 é baseado na Especificação de Sinalização Elétrica RS-485 Padrão da Associação das Indústrias Elétricas (EIA). Uma variedade de produtos Allen-Bradley (incluindo controladores SLC 500, 1784-KTX, 1747-KE, 1770-KF3 e dispositivos de interface do operador) atua como mestres de passagem de token no link DH485. Este link também suporta um modo somente resposta para dispositivos de baixo nível no link, como Decodificadores de código de barras Allen-Bradley.
Um link DH485 implementa comunicação ponto a ponto com um esquema de passagem de token para girar o domínio do link entre os nós conectados a esse link.

- Alternativa de baixo custo para programação e aquisição de dados
    
- Até 32 nós
    
- Baseado na norma RS-485
    
- Suporte a modo mestre com **passagem de token** e modo de **resposta apenas** para dispositivos simples (ex: leitores de código de barras)
