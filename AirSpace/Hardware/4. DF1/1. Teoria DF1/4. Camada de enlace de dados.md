#### Camada de link de dados
- Determina a codificação de dados no meio físico
- controla quem transmite dados e quem ouve usando um protocolo de arbitragem
- transmite pacotes de dados intactos do nó de origem para o nó de destino pelo link físico

##### Link DH, DH+ OU DH485
>Não precisa programar essa camada. Seus programas aplicativos na rede não estão envolvidos como protocolo interno, handshake ou controle do link.
##### Link DF1 entre os módulos de interface Allen Bradley
>Os módulos de interface cuidam automaticamente dessa camada. Seu programa de aplicação não precisa estar envolvido com controle de aperto de mão.
##### Link DF1 entre um módulo Allen Bradley interface e um computador
> Deve programar esta camada em seu computador.

>Você deve programar a camada de enlace de dados usando o protocolo DF1.
