
9600 8N1 - 9600 baud, 8 bits de dados, sem paridade e 1 bit de parada - é um dos protocolos seriais mais comumente usados. Então, como seria um ou dois pacotes de dados 9600 8N1? Vamos dar um exemplo!

Um dispositivo que transmite os caracteres [ASCII](http://www.asciitable.com/) 'O' e 'K' teria que criar dois pacotes de dados. O valor ASCII de _O_ (que é maiúsculo) é 79, que se divide em um valor binário de 8 bits de , enquanto o valor binário de _K_ é . Tudo o que resta é anexar bits de sincronização.
`01001111` 
`01001011`

Não é especificamente declarado, mas presume-se que os dados sejam transferidos primeiro com o bit menos significativo. Observe como cada um dos dois bytes é enviado à medida que é lido da direita para a esquerda.![[Pasted image 20250706085511.png]]

Como estamos transferindo a 9600 bps, o tempo gasto mantendo cada um desses bits alto ou baixo é 1/(9600 bps) ou 104 μs por bit.

Para cada byte de dados transmitidos, na verdade há 10 bits sendo enviados: um bit inicial, 8 bits de dados e um bit de parada. Então, a 9600 bps, estamos realmente enviando 9600 bits por segundo ou 960 (9600/10) bytes por segundo.
