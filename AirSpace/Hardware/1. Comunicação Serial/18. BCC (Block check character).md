É  um checksum de 8 bits usado para garantir a integridade da mensagem.
Ele é calculado de forma acumulativa sobre todos os bytes transmitidos a partir do primeiro byte.
imediatamente após o `DLE SOH` até o último byte `ETX` (inclusive o próprio `ETX`).

### Calculo do BCC em Half-Duplex:
>No transmissor os bytes são subtraídos do BCC e somados pelo receptor

transmissor:
```
BCC = 0
para cada byte:
    BCC = BCC - byte
    
soma = (byte1 + byte2 + ... + byteN) mod 256
BCC = ((~soma) + 1) mod 256

```
Receptor:
```
BCC = 0
para cada byte recebido:
    BCC = BCC + byte

total = (byte1 + byte2 + ... + byteN + BCC) mod 256
total == 0
```
### Calculo do BCC em Full-Duplex:
transmissor:
```
BCC = 0
para cada byte:
    BCC = BCC + byte
    
soma = (byte1 + byte2 + ... + byteN) mod 256
BCC = ((~soma) + 1) mod 256
```
```
Receptor:
BCC = 0
para cada byte recebido:
    BCC = BCC + byte
total = (byte1 + byte2 + ... + byteN + BCC) mod 256
total == 0
```
