> Linha usada pelo transmissor para **pedir permissão de envio**.

🧠 _Fluxo lógico:_

1. O PC (DTE) quer enviar → ativa RTS.
    
2. O CLP (DCE) responde ativando CTS.
    
3. Só então o PC transmite os dados pela linha TX.
    

🎯 Serve para:  
Evitar que o transmissor envie dados antes que o receptor esteja pronto (controle de fluxo físico).
