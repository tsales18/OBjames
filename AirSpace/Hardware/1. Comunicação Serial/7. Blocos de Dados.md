A verdadeira essência de cada pacote serial são os dados que ele carrega. Chamamos ambiguamente esse bloco de dados de _pedaço,_ porque seu tamanho não é especificamente declarado. A quantidade de dados em cada pacote pode ser definida para qualquer coisa de 5 a 9 bits. Certamente, o tamanho de dados padrão é o byte básico de 8 bits, mas outros tamanhos têm seus usos. Um bloco de dados de 7 bits pode ser mais eficiente do que 8, especialmente se você estiver apenas transferindo caracteres ASCII de 7 bits.

Depois de concordar com um comprimento de caracteres, ambos os dispositivos seriais também precisam concordar com a **endianidade** de seus dados. Os dados são enviados como bit mais significativo (msb) para o menor ou vice-versa? Se não for declarado o contrário, geralmente você pode assumir que os dados são transferidos **pelo bit mínimo significativo (lsb) primeiro**.
