Uma nova solução MODBUS sobre linha serial deve implementar uma interface elétrica em conformidade com o padrão EIA/TIA-485 (também conhecido como padrão RS485).
Este padrão permite sistemas ponto a ponto e multiponto, em uma configuração de dois fios. Além disso, alguns dispositivos podem implementar uma interface RS485 de quatro
fios.

Um dispositivo também pode implementar uma interface RS232.
Em um sistema MODBUS desse tipo, um dispositivo mestre e um ou mais dispositivos escravos se comunicam por meio de uma linha serial passiva.

No sistema MODBUS padrão, todos os dispositivos são conectados (em paralelo) em um cabo tronco constituído por 3 condutores. Dois desses condutores (a configuração de
“dois fios”) formam um par trançado balanceado, no qual os dados bidirecionais são transmitidos, tipicamente a uma taxa de bits de 9600 bits por segundo.

Cada dispositivo pode ser conectado:
 - diretamente no cabo principal, formando uma cadeia em série
 - seja em uma tomada passiva com um cabo de derivação
 - seja em uma tomada ativa com um cabo específico
