# PDU (Protocol Data Unit)

A PDU é a parte **puramente Modbus**.

Contém:
```
Function Code
Data
```
Exemplo: 
Leitura de Holding Registers (FC03):
 ```
 03 00 64 00 02
 
 03 -> Function Code
 00 64 -> Endereço Inicial 
 00 02 -> Quantidade de registradores
 ```

 Existem Três tipos de PDU'S
 - PDU de solicitação MODBUS, mb_req_pdu
 - PDU de resposta MODBUS, mb_rsp_pdu
 - PDU de resposta de exceção MODBUS, mb_excep_rsp_pdu

##### O mb_req_pdu é definido como:
```
mb_req_pdu = {código_da_função, dados_da_solicitação}, onde
código_da_função = [1 byte] código da função MODBUS,
dados_da_solicitação = [n bytes] Este campo depende do código da função e geralmente contém informações como referências de variáveis, contagens de variáveis, deslocamentos de dados, códigos de subfunções, etc.

```

##### O mb_rsp_pdu é definido como:
```
mb_rsp_pdu = {código_da_função, dados_da_resposta}, onde
código_da_função = [1 byte] código da função MODBUS e
dados_da_resposta = [n bytes]. Este campo depende do código da função e geralmente Contém informações como referências a variáveis,
Contagens de variáveis, deslocamentos de dados, códigos de subfunções, etc.
```

##### O mb_rsp_pdu é definido como:
```
mb_excep_rsp_pdu = {código-da-função-de-exceção, dados_da_requisição}, onde código-da-funçãode-
exceção = [1 byte] Código da função MODBUS + 0x80 código_da-exceção = [1 byte]
Código de exceção MODBUS definido na tabela
```





# ADU (Application Data Unit)

A ADU é a PDU mais tudo que o meio de transporte precisa.

No Modbus RTU:
```
ADU =  
Slave Address  
+  
PDU  
+  
CRC
```

Exemplo:
```
01 03 00 64 00 02 C5 D5

01 -> Slave Address
03 00 64 00 02 -> PDU
C5 D5 -> CRC

```
