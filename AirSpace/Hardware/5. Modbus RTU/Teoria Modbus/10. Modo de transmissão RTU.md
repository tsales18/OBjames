Quando dispositivos se comunicam em uma linha serial MODBUS usando o modo RTU (Unidade Terminal Remota), cada byte de 8 bits em uma mensagem contém dois caracteres
hexadecimais de 4 bits. A principal vantagem desse modo é que sua maior densidade de caracteres permite uma melhor taxa de transferência de dados do que o modo ASCII para a
mesma taxa de transmissão (baud rate). Cada mensagem deve ser transmitida em um fluxo contínuo de caracteres.

![[Pasted image 20260319195903.png]]

É necessária paridade par (Even); outros modos (paridade ímpar (Odd), sem paridade) também podem ser usados. Para garantir a máxima compatibilidade com outros produtos, recomenda-se
também o suporte ao modo sem paridade. O modo de paridade padrão deve ser paridade par.

Observação: a ausência de paridade requer 2 bits de parada.


Como os caracteres são transmitidos serialmente:

Cada caractere ou byte é enviado nesta ordem (da esquerda para a direita):
Bit menos significativo (LSB) ... Bit mais significativo (MSB)

![[Pasted image 20260319200118.png]]

Os dispositivos podem aceitar, por configuração, verificação de paridade par, ímpar ou nenhuma paridade. Se a verificação de nenhuma paridade for implementada, um bit de parada
adicional é transmitido para preencher o quadro de caracteres e formar um caractere assíncrono completo de 11 bits.
