A unidade de dados da aplicação MODBUS é construída pelo cliente que inicia uma transação MODBUS. A função indica ao servidor que tipo de ação deve ser executada. O protocolo de aplicação MODBUS estabelece o formato de uma solicitação iniciada por um cliente.

O campo de código de função de uma unidade de dados MODBUS é codificado em um byte. Os códigos válidos
estão no intervalo de 1 a 255 em decimal (o intervalo de 128 a 255 é reservado e usado para respostas de exceção).
Quando uma mensagem é enviada de um Cliente para um Servidor, o campo de código de função informa ao
servidor qual ação executar. O código de função "0" não é válido.

Códigos de subfunção são adicionados a alguns códigos de função para definir múltiplas ações.
O campo de dados das mensagens enviadas de um cliente para um servidor contém informações adicionais que o
servidor utiliza para executar a ação definida pelo código da função. Isso pode incluir itens como endereços discretos
e de registro, a quantidade de itens a serem processados e a contagem de bytes de dados reais no campo.

Em certos tipos de requisições, o campo de dados pode ser inexistente (ter comprimento zero); nesse caso, o servidor não exige
nenhuma informação adicional. O código da função, por si só, especifica a ação

Se não ocorrer nenhum erro relacionado à função MODBUS solicitada em uma ADU MODBUS recebida
corretamente, o campo de dados da resposta do servidor para o cliente conterá os dados solicitados. Se ocorrer um
erro relacionado à função MODBUS solicitada, o campo conterá um código de exceção que o aplicativo servidor poderá usar para determinar a próxima ação a ser tomada.
Por exemplo, um cliente pode ler os estados LIGADO/DESLIGADO de um grupo de saídas ou entradas discretas,
ou pode ler/escrever o conteúdo de dados de um grupo de registradores.
Quando o servidor responde ao cliente, ele usa o campo de código de função para indicar se a resposta foi normal (sem erros) ou se
ocorreu algum tipo de erro (chamada de resposta de exceção). Para uma resposta normal, o servidor simplesmente retorna o código
de função original à solicitação.
