Existem três categorias de códigos de funções MODBUS. São elas:

##### Códigos de função pública
- São códigos de função bem definidos garantidamente únicos
- Validado pela comunidade MODBUS.org
- Documentado publicamente
- Disponibilizamos testes de conformidade
- Inclui tanto códigos de função atribuídos publicamente quanto funções não atribuídas. Códigos reservados para uso futuro.

##### Códigos de função definidos pelo usuário
- Existem duas faixas de códigos de função definidos pelo usuário, ou seja, de 65 a 72 e de 100 a 110. decimal.
- O usuário pode selecionar e implementar um código de função que não é suportado pelo especificação.
- Não há garantia de que o uso do código de função selecionado será único.
- Se o usuário quiser reposicionar a funcionalidade como um código de função público, ele deve Iniciar uma RFC para introduzir a alteração na categoria pública e para ter uma nova Código de função pública atribuído.


##### Códigos de função reservados 
- Códigos de função atualmente usados por algumas empresas para produtos legados e que não estão disponíveis para uso público.
