Cria ou abre um arquivo ou dispositivo de E/S. Os dispositivos de E/S mais comumente usados ​​são: arquivo, fluxo de arquivos, diretório, disco físico, volume, buffer de console, unidade de fita, recurso de comunicação, slot de correio e pipe. A função retorna um identificador que pode ser usado para acessar o arquivo ou dispositivo para vários tipos de E/S, dependendo do arquivo ou dispositivo e dos sinalizadores e atributos especificados.

Sintaxe:
```
HANDLE CreateFileA(

  [in]           LPCSTR                lpFileName,

  [in]           DWORD                 dwDesiredAccess,

  [in]           DWORD                 dwShareMode,

  [in, optional] LPSECURITY_ATTRIBUTES lpSecurityAttributes,

  [in]           DWORD                 dwCreationDisposition,

  [in]           DWORD                 dwFlagsAndAttributes,

  [in, optional] HANDLE                hTemplateFile

);
```

# Parâmetros


## `[in] lpFileName:`

O nome do arquivo ou dispositivo a ser criado ou aberto. Você pode usar barras (/) ou barras invertidas () neste nome


## `[in] dwDesiredAccess`
O acesso solicitado ao arquivo ou dispositivo, que pode ser resumido como leitura, gravação, ambos ou 0 para indicar nenhum).

| Constant                              | Generic meaning            |
| ------------------------------------- | -------------------------- |
| **GENERIC_ALL**  <br>`0x10000000`     | All possible access rights |
| **GENERIC_EXECUTE**  <br>`0x20000000` | Execute access             |
| **GENERIC_WRITE**  <br>`0x40000000`   | Write access               |
| **GENERIC_READ**  <br>`0x80000000`    | Read access                |
Se este parâmetro for zero, o aplicativo poderá consultar determinados metadados, como atributos de arquivo, diretório ou dispositivo, sem acessar esse arquivo ou dispositivo, mesmo que o acesso **GENERIC_READ** tenha sido negado.

Você não pode solicitar um modo de acesso que entre em conflito com o modo de compartilhamento especificado pelo parâmetro _dwShareMode_ em uma solicitação aberta que já tenha um identificador aberto.

## `[in] dwShareMode`
O modo de compartilhamento solicitado do arquivo ou dispositivo, que pode ser leitura, gravação, ambos, exclusão, todos esses, ou nenhum (consulte a tabela a seguir). Solicitações de acesso a atributos ou atributos estendidos não são afetadas por este sinalizador.

Se este parâmetro for zero e **CreateFile** for bem-sucedido, o arquivo ou dispositivo não poderá ser compartilhado e não poderá ser aberto novamente até que o identificador do arquivo ou dispositivo seja fechado. Para mais informações, consulte a seção Observações.

Para permitir que um processo compartilhe um arquivo ou dispositivo enquanto outro processo mantém o arquivo ou dispositivo aberto, use uma combinação compatível de um ou mais dos seguintes valores.

|                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **0**<br><br>0x00000000                         | Impede que outros processos abram um arquivo ou dispositivo se solicitarem acesso de exclusão, leitura ou gravação.                                                                                                                                                                                                                                                                                                      |
| **FILE_SHARE_DELETE**<br><br>0x00000004<br><br> | Permite que operações abertas subsequentes em um arquivo ou dispositivo solicitem acesso de exclusão.<br><br>Caso contrário, outros processos não poderão abrir o arquivo ou dispositivo se solicitarem acesso de exclusão.<br><br>Se este sinalizador não for especificado, mas o arquivo ou dispositivo tiver sido aberto para acesso de exclusão, a função falhará.                                                   |
| **FILE_SHARE_READ**<br><br>0x00000001<br><br>   | Permite que operações abertas subsequentes em um arquivo ou dispositivo solicitem acesso de leitura.<br><br>Caso contrário, outros processos não poderão abrir o arquivo ou dispositivo se solicitarem acesso de leitura.<br><br>Se este sinalizador não for especificado, mas o arquivo ou dispositivo tiver sido aberto para acesso de leitura, a função falhará.                                                      |
| **FILE_SHARE_WRITE**<br><br>0x00000002<br><br>  | Permite que operações abertas subsequentes em um arquivo ou dispositivo solicitem acesso de gravação. Caso contrário, outros processos não poderão abrir o arquivo ou dispositivo se solicitarem acesso de gravação.<br><br>Se este sinalizador não for especificado, mas o arquivo ou dispositivo tiver sido aberto para acesso de gravação ou tiver um mapeamento de arquivo com acesso de gravação, a função falhará. |

## `[in,optional] lpSecurityAttributes`

Um ponteiro para uma estrutura [SECURITY_ATTRIBUTES](https://learn.microsoft.com/en-us/windows/win32/api/wtypesbase/ns-wtypesbase-security_attributes) que contém dois membros de dados separados, mas relacionados: um descritor de segurança opcional e um valor booleano que determina se o identificador retornado pode ser herdado por processos filho.

Este parâmetro pode ser **NULL** .

Se este parâmetro for **NULL** , o identificador retornado por **CreateFile** não poderá ser herdado por nenhum processo filho que o aplicativo possa criar e o arquivo ou dispositivo associado ao identificador retornado receberá um descritor de segurança padrão.

O membro **lpSecurityDescriptor** da estrutura especifica um [SECURITY_DESCRIPTOR](https://learn.microsoft.com/en-us/windows/desktop/api/winnt/ns-winnt-security_descriptor) para um arquivo ou dispositivo. Se este membro for **NULL** , o arquivo ou dispositivo associado ao identificador retornado receberá um descritor de segurança padrão.

**CreateFile** ignora o membro **lpSecurityDescriptor** ao abrir um arquivo ou dispositivo existente, mas continua a usar o membro **bInheritHandle** .

O membro **bInheritHandle** da estrutura especifica se o identificador retornado pode ser herdado.
## `[in] dwCreationDisposition`
Uma ação a ser executada em um arquivo ou dispositivo que existe ou não existe.

Para dispositivos diferentes de arquivos, esse parâmetro geralmente é definido como **OPEN_EXISTING** .

Para mais informações, consulte a seção Observações.

Este parâmetro deve ser um dos seguintes valores, que não podem ser combinados:

| Valor                          | Significado                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CREATE_ALWAYS**<br><br>2     | Cria um novo arquivo, sempre.<br><br>Se o arquivo especificado existir e for gravável, a função truncará o arquivo, a função será bem-sucedida e o código do último erro será definido como **ERROR_ALREADY_EXISTS** (183).<br><br>Se o arquivo especificado não existir e for um caminho válido, um novo arquivo será criado, a função será bem-sucedida e o código do último erro será definido como zero.<br><br>Para mais informações, consulte a seção Observações deste tópico. |
| **CREATE_NEW**<br><br>1        | Cria um novo arquivo, somente se ele ainda não existir.<br><br>Se o arquivo especificado existir, a função falhará e o último código de erro será definido como **ERROR_FILE_EXISTS** (80).<br><br>Se o arquivo especificado não existir e for um caminho válido para um local gravável, um novo arquivo será criado.                                                                                                                                                                 |
| **OPEN_ALWAYS**<br><br>4       | Abre um arquivo, sempre.<br><br>Se o arquivo especificado existir, a função será bem-sucedida e o último código de erro será definido como **ERROR_ALREADY_EXISTS** (183).<br><br>Se o arquivo especificado não existir e for um caminho válido para um local gravável, a função criará um arquivo e o código do último erro será definido como zero.                                                                                                                                 |
| **OPEN_EXISTING**<br><br>3     | Abre um arquivo ou dispositivo, somente se ele existir.<br><br>Se o arquivo ou dispositivo especificado não existir, a função falhará e o último código de erro será definido como **ERROR_FILE_NOT_FOUND** (2).<br><br>Para mais informações sobre dispositivos, consulte a seção Observações.                                                                                                                                                                                       |
| **TRUNCATE_EXISTING**<br><br>5 | \|   \|<br>\|---\|<br>\|Abre um arquivo e o trunca para que seu tamanho seja zero bytes, somente se ele existir.<br><br>Se o arquivo especificado não existir, a função falhará e o último código de erro será definido como **ERROR_FILE_NOT_FOUND** (2).<br><br>O processo de chamada deve abrir o arquivo com o bit **GENERIC_WRITE** definido como parte do parâmetro _dwDesiredAccess ._\|                                                                                       |

## `[in] dwFlagsAndAttributes`
Os atributos e sinalizadores do arquivo ou dispositivo, sendo **FILE_ATTRIBUTE_NORMAL** o valor padrão mais comum para arquivos.

Este parâmetro pode incluir qualquer combinação dos atributos de arquivo disponíveis ( **FILE_ATTRIBUTE_*** ). Todos os outros atributos de arquivo substituem **FILE_ATTRIBUTE_NORMAL** .

Este parâmetro também pode conter combinações de sinalizadores ( **FILE_FLAG_*** ) para controle do comportamento de cache de arquivos ou dispositivos, modos de acesso e outros sinalizadores de propósito específico. Estes se combinam com quaisquer valores **FILE_ATTRIBUTE_*** .

Este parâmetro também pode conter informações de Qualidade de Serviço de Segurança (SQOS) especificando o sinalizador **SECURITY_SQOS_PRESENT** . Informações adicionais sobre sinalizadores relacionados ao SQOS são apresentadas na tabela a seguir às tabelas de atributos e sinalizadores.


| Atributo                                           | Significado                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **FILE_ATTRIBUTE_ARCHIVE**<br><br>32 (0x20)        | O arquivo deve ser arquivado. Os aplicativos usam este atributo para marcar arquivos para backup ou remoção.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **FILE_ATTRIBUTE_ENCRYPTED**<br><br>16384 (0x4000) | O arquivo ou diretório está criptografado. Para um arquivo, isso significa que todos os dados nele contidos estão criptografados. Para um diretório, isso significa que a criptografia é o padrão para arquivos e subdiretórios recém-criados. Para mais informações, consulte [Criptografia de Arquivos](https://learn.microsoft.com/en-us/windows/desktop/FileIO/file-encryption) .<br><br>Este sinalizador não terá efeito se **FILE_ATTRIBUTE_SYSTEM** também for especificado.<br><br>Este sinalizador não é compatível com as edições Home, Home Premium, Starter ou ARM do Windows. |
| **FILE_ATTRIBUTE_HIDDEN**<br><br>2 (0x2)           | O arquivo está oculto. Não o inclua em uma listagem de diretório comum.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **FILE_ATTRIBUTE_NORMAL**<br><br>128 (0x80)        | O arquivo não possui outros atributos definidos. Este atributo só é válido se usado sozinho.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **FILE_ATTRIBUTE_OFFLINE**<br><br>4096 (0x1000)    | Os dados de um arquivo não estão imediatamente disponíveis. Este atributo indica que os dados do arquivo foram fisicamente movidos para o armazenamento offline. Este atributo é usado pelo Armazenamento Remoto, o software de gerenciamento de armazenamento hierárquico. Os aplicativos não devem alterar este atributo arbitrariamente.                                                                                                                                                                                                                                                |
| **FILE_ATTRIBUTE_READONLY**<br><br>1 (0x1)         | O arquivo é somente leitura. Os aplicativos podem ler o arquivo, mas não podem gravar nele nem excluí-lo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **FILE_ATTRIBUTE_SYSTEM**<br><br>4 (0x4)           | O arquivo faz parte ou é usado exclusivamente por um sistema operacional.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **FILE_ATTRIBUTE_TEMPORARY**<br><br>256 (0x100)    | O arquivo está sendo usado para armazenamento temporário.<br><br>Para obter mais informações, consulte a seção [Comportamento de cache](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilea#caching_behavior) deste tópico.                                                                                                                                                                                                                                                                                                                                 |
