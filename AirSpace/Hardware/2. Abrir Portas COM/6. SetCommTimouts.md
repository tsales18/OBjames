Define os parâmetros de tempo limite para todas as operações de leitura e gravação em um dispositivo de comunicação especificado.

Sintaxe:
```
BOOL SetCommTimeouts(
  [in] HANDLE         hFile,
  [in] LPCOMMTIMEOUTS lpCommTimeouts
);
```
## Parâmetros

`[in] hFile`

Um identificador para o dispositivo de comunicação. A função [CreateFile](https://learn.microsoft.com/en-us/windows/desktop/api/fileapi/nf-fileapi-createfilea) retorna este identificador.

`[in] lpCommTimeouts`

Um ponteiro para uma estrutura [COMMTIMEOUTS](https://learn.microsoft.com/en-us/windows/desktop/api/winbase/ns-winbase-commtimeouts) que contém os novos valores de tempo limite.

## Valor de retorno

Se a função for bem-sucedida, o valor de retorno será diferente de zero.

Se a função falhar, o valor de retorno será zero. Para obter informações de erro mais detalhadas, chame [GetLastError](https://learn.microsoft.com/en-us/windows/desktop/api/errhandlingapi/nf-errhandlingapi-getlasterror) .
