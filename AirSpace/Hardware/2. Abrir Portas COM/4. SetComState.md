Configura um dispositivo de comunicação de acordo com as especificações de um bloco de controle de dispositivo (uma estrutura [DCB](https://learn.microsoft.com/en-us/windows/desktop/api/winbase/ns-winbase-dcb) ). A função reinicializa todas as configurações de hardware e controle, mas não esvazia as filas de saída ou entrada.

```
BOOL SetCommState(
  [in] HANDLE hFile,
  [in] LPDCB  lpDCB
);
```

## `[in] hFile`
Um identificador para o dispositivo de comunicação. A função [CreateFile](https://learn.microsoft.com/en-us/windows/desktop/api/fileapi/nf-fileapi-createfilea) retorna este identificador.

## `[in] lpDCB`
Um ponteiro para uma estrutura [DCB](https://learn.microsoft.com/en-us/windows/desktop/api/winbase/ns-winbase-dcb) que contém as informações de configuração para o dispositivo de comunicação especificado.

## ``Valor de retorno``

Se a função for bem-sucedida, o valor de retorno será diferente de zero.

Se a função falhar, o valor de retorno será zero. Para obter informações de erro mais detalhadas, chame [GetLastError](https://learn.microsoft.com/en-us/windows/desktop/api/errhandlingapi/nf-errhandlingapi-getlasterror) .
