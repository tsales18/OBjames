O protocolo MODBUS Serial Line é um protocolo mestre-escravo. Apenas um mestre (por vez) está conectado ao barramento, e um ou mais nós escravos (máximo de 247)
também estão conectados ao mesmo barramento serial. Uma comunicação MODBUS é sempre iniciada pelo mestre. Os nós escravos nunca transmitirão dados sem receber
uma solicitação do mestre. Os nós escravos nunca se comunicarão entre si. O mestre inicia apenas uma transação MODBUS por vez.

###### O nó mestre envia uma solicitação MODBUS aos nós escravos em dois modos:
  No ``modo unicast``, o mestre se dirige a um escravo individual. Após receber e processar a solicitação, o escravo retorna um mensagem (uma 'resposta') ao mestre.
  Nesse modo, uma transação MODBUS consiste em 2 mensagens: uma solicitação do mestre e uma resposta do escravo.
  No modo de transmissão, o mestre pode enviar uma solicitação a todos os escravos.
  
  No ``modo de transmissão``, o mestre pode enviar uma solicitação a todos os escravos.
  Nenhuma resposta é retornada às solicitações de transmissão enviadas pelo mestre. As solicitações de transmissão são necessariamente comandos de escrita. Todos os
  dispositivos devem aceitar a transmissão para a função de escrita. O endereço 0 é reservado para identificar uma troca de transmissão.
