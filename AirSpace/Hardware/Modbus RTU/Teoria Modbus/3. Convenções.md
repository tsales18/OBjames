Neste documento, as seguintes palavras são usadas para definir a importância de cada requisito específico. 

"DEVE" / "REQUERIDO" / "MUST" / "REQUIRED"

Todos os requisitos que contêm a palavra "DEVE" são obrigatórios. A palavra "DEVE", ou o adjetivo "REQUERIDO", significa que o item é um requisito absoluto para a implementação. Essas palavras estão sublinhadas. 

"DEVERIA" / "RECOMENDADO" / "SHOULD" / "RECOMMENDED"

Todas as recomendações que contêm a palavra "DEVERIA" ou o adjetivo "RECOMENDADO" são consideradas comportamentos desejados. Essas recomendações devem ser usadas como um guia ao escolher entre diferentes opções para implementar a funcionalidade. Pode haver razões válidas em circunstâncias específicas para ignorar este item, mas todas as implicações devem ser compreendidas e o caso cuidadosamente avaliado antes de optar por um caminho diferente. Essas palavras estão sublinhadas. 

"PODE" / "OPCIONAL" / "MAY" / "OPTIONAL"

A palavra "PODE", ou o adjetivo "OPCIONAL", significa que este item é verdadeiramente opcional. Um designer pode optar por incluir o item porque um determinado mercado o exige ou porque ele aprimora o produto, por exemplo; outro designer pode omitir o mesmo item
