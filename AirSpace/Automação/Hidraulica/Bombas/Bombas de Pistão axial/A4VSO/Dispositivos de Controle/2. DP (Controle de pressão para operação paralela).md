É também controle de pressão, mas preparado para operação de várias bombas em paralelo.

imagine duas ou três 4VSO alimentando o mesmo coletor. Se você simplesmente colocasse, compensadores DR independentes, pequenas diferenças de ajuste poderiam fazer.

- uma bomba assumir quase toda carga
- outra destrocar.
- ocorrer instabilidade entre os reguladores.

O DP possui uma estratégia apropriada para compartilhamento/controle de pressão em operação
paralela, portanto:

DR = uma bomba controlando pressão

DP = controle de pressão pensado para bombas trabalhando em paralelo.
